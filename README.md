# КриптоСдача

Налоговый и бухгалтерский консалтинг по криптовалюте — для физлиц и компаний в РФ.

## Структура

```
criptosdacha/
├── index.html           # Главная (два направления: физикам/юрикам + калькулятор)
├── services.html        # Услуги для физлиц
├── business.html        # Для бизнеса (крипто-бухгалтерия, ВЭД)
├── how-it-works.html    # Как работает (консалтинговый процесс)
├── blog.html            # Блог
├── contacts.html        # Контакты
├── css/styles.css       # Общий дизайн (Manrope + teal #22A085)
└── js/main.js           # Калькулятор, мобильное меню, FAQ
```

## Локальный запуск

```bash
python3 -m http.server 8000
# или
npx serve
```

Откройте http://localhost:8000

## Технологии

- HTML / CSS / Vanilla JS — без фреймворков
- Шрифт: Manrope (Google Fonts)
- Адаптивный дизайн, mobile-first
