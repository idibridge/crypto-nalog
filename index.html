Процесс

Три шага до готовой декларации

Никаких данных банковских карт. Только история сделок через read-only API или CSV-выгрузку.

01

Загрузить сделки

API-ключ Binance / Bybit / OKX (только просмотр), CSV-выписка с биржи или адрес on-chain кошелька. Поддерживаем 22+ источников.

02

Авто-расчёт по ФНС

Метод FIFO. Конвертация по курсу ЦБ на дату операции. Майнинг, стейкинг, эйрдропы и P2P считаются отдельно.

03

Готовая 3-НДФЛ

PDF + XML для загрузки в личный кабинет ФНС. Шаблон уведомления о зарубежных кошельках к дедлайну 1 июля.
