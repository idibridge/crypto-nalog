# Google Search Console + Яндекс.Вебмастер — пошагово

Это нужно делать руками в браузере под своим аккаунтом — я не могу залогиниться
за тебя ни в Google, ни в Яндекс. Но весь сайт уже готов к подключению:
`sitemap.xml`, `robots.txt` и места под verification-теги в `index.html` есть.

## Google Search Console

1. Зайди на https://search.google.com/search-console и войди под своим Google-аккаунтом.
2. «Добавить ресурс» → выбери **«Тег HTML»** как способ подтверждения (не доменную
   проверку через DNS — для неё нужен доступ к DNS, а домен администрирует друг).
3. Google даст строку вида:
   `<meta name="google-site-verification" content="abc123..." />`
4. Открой `index.html`, найди закомментированную строку:
   ```html
   <!-- <meta name="google-site-verification" content="ВАШ_КОД_ОТ_GOOGLE"> -->
   ```
   Раскомментируй её и вставь свой код вместо `ВАШ_КОД_ОТ_GOOGLE`.
5. Запушь изменения на GitHub (см. главный README, раздел «Как опубликовать»),
   дождись, пока GitHub Pages обновится (обычно 1–2 минуты).
6. Вернись в Search Console и нажми «Подтвердить».
7. После подтверждения: Sitemaps → вставь `sitemap.xml` → отправить.
   Полный адрес: `https://cryptosdacha.ru/sitemap.xml`.

## Яндекс.Вебмастер

1. Зайди на https://webmaster.yandex.ru и войди под своим Яндекс-аккаунтом.
2. «Добавить сайт» → `cryptosdacha.ru`.
3. Способ подтверждения — **«Мета-тег»**.
4. Яндекс даст строку вида:
   `<meta name="yandex-verification" content="xyz789" />`
5. В `index.html` раскомментируй вторую заготовку и вставь код:
   ```html
   <meta name="yandex-verification" content="xyz789" />
   ```
6. Запушь на GitHub, дождись обновления Pages, нажми «Проверить» в Вебмастере.
7. После подтверждения: Индексирование → Файлы Sitemap → добавь
   `https://cryptosdacha.ru/sitemap.xml`.
8. Там же стоит сразу заполнить «Регион» (Россия) и проверить, что robots.txt
   подхватился (Инструменты → Анализ robots.txt).

## После подключения обоих

- Раз в одну-две недели проверяй разделы «Покрытие» / «Индексирование» — обе
  системы подскажут, если какая-то страница не проиндексировалась.
- Когда добавишь Яндекс.Метрику или Google Analytics — это отдельный шаг,
  не связанный с Вебмастером/Search Console напрямую.
