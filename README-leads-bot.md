# Telegram-бот для заявок с сайта — пошагово

Сайт статический (GitHub Pages), поэтому форме нужен внешний бесплатный
обработчик. Использован **Cloudflare Workers** (бесплатный тариф, 100 000
запросов/день — заявок с сайта столько не будет никогда). Код обработчика —
файл `leads-bot/worker.js` в этом архиве.

Как это работает: пользователь жмёт «Отправить заявку» → браузер шлёт данные
формы на Cloudflare Worker → Worker форматирует сообщение и шлёт его в
Telegram через Bot API → ты получаешь сообщение в чате/канале.

## Шаг 1. Создать бота

1. В Telegram открой **@BotFather**.
2. `/newbot` → придумай имя (например, «КриптоСдача — заявки») → придумай
   username, обязательно заканчивается на `bot` (например `cryptosdacha_leads_bot`).
3. BotFather выдаст **токен** вида `123456789:AAH...`. Сохрани его — это
   секрет, не публикуй и не клади в код на GitHub.

## Шаг 2. Узнать chat_id, куда слать заявки

Проще всего — личный чат с самим ботом:

1. Найди своего бота в Telegram (по username) и нажми «Start» / отправь любое
   сообщение.
2. Открой в браузере (подставь свой токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
3. В ответе (JSON) найди `"chat":{"id": ЧИСЛО, ...}` — это и есть `CHAT_ID`.
   Число может быть отрицательным, если это группа — это нормально, копируй
   как есть.

Если хочешь, чтобы заявки видели и ты, и Максим — создай отдельную приватную
группу в Telegram, добавь туда бота, напиши в группе любое сообщение и возьми
`chat_id` группы тем же способом (он будет отрицательным, например `-100123...`).

## Шаг 3. Развернуть Cloudflare Worker (бесплатно, через браузер)

1. Зарегистрируйся на https://dash.cloudflare.com (бесплатный аккаунт,
   платёжные данные не нужны для Workers free-плана).
2. В боковом меню: **Workers & Pages** → **Create** → **Create Worker**.
3. Дай имя, например `cryptosdacha-leads` → Deploy (создаст заготовку).
4. Открой созданный Worker → **Edit code**.
5. Удали содержимое редактора и вставь код из файла `leads-bot/worker.js`
   (целиком).
6. **Save and deploy**.
7. Перейди в **Settings → Variables and Secrets** этого Worker'а, добавь три
   переменные (тип — **Secret**, не «Text», чтобы не светились в логах):
   - `BOT_TOKEN` — токен из шага 1
   - `CHAT_ID` — id из шага 2
   - `ALLOWED_ORIGIN` — `https://cryptosdacha.ru`
8. Сохрани. После сохранения секретов Worker передеплоится автоматически.
9. На странице Worker'а скопируй его адрес — что-то вроде:
   `https://cryptosdacha-leads.ТВОЙ-АККАУНТ.workers.dev`

## Шаг 4. Подключить адрес Worker'а к сайту

1. Открой `contacts/index.html` (уже лежит в архиве сайта), найди строку:
   ```js
   const LEAD_FORM_ENDPOINT = "https://YOUR-WORKER-SUBDOMAIN.workers.dev";
   ```
2. Замени на свой реальный адрес из шага 3.9.
3. Сохрани, запушь на GitHub вместе с остальными изменениями.

## Шаг 5. Проверить

1. Открой `https://cryptosdacha.ru/contacts/` (после публикации), заполни
   форму тестовыми данными, отправь.
2. В Telegram должно прийти сообщение вида:
   ```
   🟢 Новая заявка — КриптоСдача

   Имя: ...
   Email: ...
   Тема: ...
   Сообщение:
   ...
   ```
3. Если не пришло — проверь в Cloudflare: Worker → **Logs** (Real-time Logs),
   там видно ошибки (неверный токен, неверный chat_id и т.д.)

## Что уже встроено в форму

- **Honeypot-поле** (`name="company"`) — невидимое для людей поле-ловушка
  для простых ботов-спамеров. Если оно заполнено, Worker тихо отвечает
  «успех», но в Telegram ничего не шлёт.
- Обязательный чекбокс согласия на обработку персональных данных со ссылкой
  на `/privacy/`.
- При ошибке сети форма не «зависает» — показывает сообщение и предлагает
  написать в Telegram напрямую.

## На будущее (из идей Максима)

Когда понадобится не просто «получить сообщение в Telegram», а полноценный
бот с диалогом (кнопки, статусы заявки и т.д.) — это уже отдельный проект
поверх того же бота (Telegram Bot API поддерживает и приём команд, не только
отправку). Текущий Worker — только «форма → Telegram», этого достаточно для
старта.
